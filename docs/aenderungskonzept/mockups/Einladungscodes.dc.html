Rolle nach der Freischaltung

Den Code mit QR-Code und „Aushang drucken“ gibt es nur direkt nach dem Erstellen. Später kennt der Server nur noch eine Prüfsumme; für einen neuen Aushang einen neuen Code erstellen.

Die Rolle „Admin“ gibt es für Codes nicht: Wer einen Aushang fotografiert, soll nie Admin werden können. Admins ernennen Sie unter „Konten“.

So läuft es ab

  1. Die Person registriert sich mit dem Aushang „Geräteträger“ und bestätigt ihre E-Mail.
  2. Unter „Konten“ erscheint sie als wartend, mit der Rolle aus dem Code vorausgewählt.
  3. Der Admin prüft den Namen, ändert bei Bedarf die Rolle und schaltet frei.
